# S1：成本分布与偷任务

2026-10-25 · Codex · tx；依据 [阶段3完整结果](../measurements/2026-10-25-phase3-tx/README.md)。数据派生与计时边界见 [方法](phase3-method.md)。

## 1. 问题

历史周期夹具把重任务绑定到固定队列，不能推导真实分布下的收益。本轮对真实 Bistro 网格归约耗时派生、重采样的 CPU 成本代理进行验证，不把它称为实际引擎几何吞吐。

## 2. 朴素基线

按任务 ID % workers 静态分发、不跨队列偷取。为满足 Chase-Lev 的单 owner 约束，四种自研策略共用一个专用实验池和外部 producer inbox；该池不为每个任务分配 future，不等同于 S2 测量的原 JobSystem，不能直接与历史吞吐拼表。关闭偷取的 static 路径是本轮基线，@aa 重复同一路径。

## 3. 定位方法

用确定性成本向量计算 max(静态队列成本)/mean，并记录 idle_fraction、search_fraction、偷取尝试/成功/搬移次数。100k 实数分布、4 workers 的成本不均指标仅 **1.007374**：理想静态负载已经接近均衡，不能预设会再次出现3.6倍。该比值是忽略所有调度开销的负载模型，不是更换队列实现后所有性能收益的严格上界。

## 4. 假设

偷取能填补不均衡，但细任务下其额外扫描、锁、通知和同步成本可能超过收益。真实成本重采样使大样本队列总成本趋于均衡；“收益接近负载上限”的原猜想须结合开销验证，不能从模型直接得出结论。

## 5. 改动

新增偷一、一次偷半与固定容量 Chase-Lev。互斥队列 owner 取新、thief 取旧；偷半搬移受害队列半批到本地。Chase-Lev 的索引与槽为 SC 原子，最后元素由 top CAS 仲裁，不做运行期扩容/回收；外部入口仍有锁。S1 路径不改变原 JobSystem 默认行为。oneTBB、Taskflow、T 个分片的 std::async 为同负载外部参照，分片模型明确不同。

## 6. 对照实验

10^5 实数分布及均匀控制 × 1/2/4/8 workers × 两口径 × 7实现，另有10^6实数分布 ×4 workers。每配置预热1轮、正式10轮、独立@aa、轮换顺序。8线程标超订，不外推为8核扩展。逐ID、工作摘要及成本独立答案核验；无stub或无效轮次。实验线程池、计时与库的准确边界见方法文件。

## 7. 指标与结果

4 workers / real-100000，相对static的配对吞吐：

| 口径 | 策略 | 中位比值 [min,max] | 判定 |
|---|---|---|---|
| prequeued | 偷一 | 1.191 [0.986,1.655] | 无显著提升 |
| prequeued | 偷半 | 1.103 [0.799,1.668] | 无显著提升 |
| prequeued | Chase-Lev | 1.162 [0.987,1.789] | 无显著提升；A/A为[0.545,1.662] |
| end_to_end | Chase-Lev | 0.741 [0.625,0.806] | 显著变慢；A/A为[0.813,1.204] |
| end_to_end | oneTBB | 0.658 [0.504,0.717] | 显著变慢 |
| end_to_end | async分片 | 2.556 [1.612,3.429] | 此执行模型显著更快，不能当作通用库排名 |

百万任务的4线程Chase-Lev预入队比值1.064 [0.783,1.144]，端到端0.725 [0.404,0.927]，均判无显著提升。相应A/A很宽，不将较低中位数单独包装为显著结论。

在100k/4T预入队组，静态/偷一/偷半/Chase的睡眠占比中位数约6.47%/0.064%/0.063%/0.873%，选任务/转移占比约23.1%/29.2%/27.9%/25.2%。睡得少不等于吞吐显著提升；两类计时本身也有观测成本。完整线程数、均匀控制、范围和flags均保留在原始目录与throughput-comparisons.csv。

## 8. 代价与取舍

inbox、多次扫描、偷半的批次存储、逐ID原子校验及保守SC序均有成本；固定容量与任务存储生命周期约束不适合作为未经扩展的生产执行器。不能把本轮回退归结为“无锁一定更慢”，更不能据此改变L3的稳定默认策略。共享VM常驻服务与宿主噪声未隔离，A/A重叠的项按规则不宣称收益。

## 9. 反向验证

均匀控制4T预入队：偷一0.964、偷半1.037、Chase1.052，均无显著提升。static关闭偷取回到同一基线路径，@aa量化其运行噪声。TSan覆盖环形回绕、空队列pop、末元素竞争、4 thief与4 producer压力；每个ID恰好一次，全部通过。Windows/多物理核补测依原方案阶段8，本轮未验证。
