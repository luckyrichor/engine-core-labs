## 使用边界

- 合成任务用迭代次数代表成本。区间均匀分布在整数迭代上离散化，不是采集的生产任务大小分布。不同占比 / 倍数的总工作量不同，只比较同输入的双策略配对比值。
- 四 vCPU 机器上八线程为过量订阅。十轮 SD 含输入和运行差异，不是置信区间；loadavg 有历史记忆，不能单独判后台争用。
- 仍有锁、原子和 future 开销。未实现 Chase-Lev，尚无证据说明必须换成无锁队列。池内任务不能等待 / 关闭自身池；外部 pause / shutdown 串行调用。
- batch p99 是批均摊值；单次插桩包括读钟与系统噪声。Arena reset 是一次操作，现有数据不能解析固有成本，不再把约 0.117 ns 的摊薄底噪当作 reset 延迟。
- 首次触页控制用匿名 mmap 保证新映射；malloc 增长的是存活集，不保证每次调用引发操作系统堆扩展。页故障不是磁盘 I/O，冷路径不是 CPU 冷缓存；不据此建立 Pool / Stack / Arena 排名。
- 固定 Pool 不需要连续空闲，不能用变长堆的外部碎片指标衡量。Arena reset 不调用析构，分配器非线程安全。
- 动态 sanitizer 覆盖运行到的路径，不证明全部并发时序。L3已完成同步/异步/预加载实验，真实热文件+合成解码，不含GPU或真实引擎场景。

当前 L3 入口与三种方式代价见 experiments/l3-resource-loading/README.md；最新数据 2026-10-15-l3。异步需求到安装 p99 约10.2ms，预加载启动约17.1ms；本轮缓冲复用差距落在 A/A 噪声内，默认保留 vector。3 workers 的 p99 有变化但最大尖峰仍在，guest steal 全0也不能证明主线程未被抢占。
